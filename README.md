# Acta PRICE — Semana 04

App Android de fiscalización y generación del **Acta PRICE**, con API REST de sincronización y paquete de entrega.

## Inicio rápido
- **App:** abrir esta carpeta en Android Studio → Run `app`
- **Entrega completa (API, SQL, Postman, docs, evidencias):** ver [`entrega/README.md`](entrega/README.md)

## Estructura principal
- `app/` — proyecto Android
- `entrega/` — API, script SQLite, Postman, documento técnico y carpeta de evidencias
